# A reading room, not another landing-page dashboard

The UI is a task workspace: dark green access rail, horizontal case tabs on narrow screens, a folder-framed scanned page, ochre OCR word highlights and an independent reviewer form. Numeric evidence, original source and image-attested corrections remain visibly distinct.

Outside interaction research: IIIF's annotation recipe shows how annotations can target parts of source images, https://iiif.io/api/cookbook/recipe/0021-tagging/ . Docket borrows the source/region interaction idea, not IIIF protocol conformance or copied code/artwork. All layout, source overlays, symbols and CSS are original. The font bundled for synthetic scans retains its DejaVu license. No network fonts or remote image assets.

Live source/queue, saved OCR evaluation and actual model-study summaries have separate labels. Reviewer draft revisions stay pinned until save/reload, avoiding polling overwrites. Viewer mode receives redacted OCR and cannot obtain images or perform writes. Redaction is a finite tested view aid; operational logging instead excludes raw content by construction.
